Entry for the [make.fun bounty "The Houseplant Out-of-Office"](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047): one out-of-office auto-reply, at most 120 characters, as if a houseplant had written it.

`main.py` writes 10 fresh candidate one-liners, scores each against the judge's published brief (plant voice, surprise, plant life driving the joke, tightness, originality), and writes the highest-scoring line to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
